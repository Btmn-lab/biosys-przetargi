# Aktualne przetargi dla Biosys

Publiczny raport KD/SKD i RCP. Strona: https://btmn-lab.github.io/biosys-przetargi/

Źródłem danych są strony instytucji, BIP i oficjalne ogłoszenia BZP.
Raport pokazuje wyłącznie postępowania z przyszłym terminem i bez rozpoznanego zamknięcia.
Przeglądarka ukrywa oferty po terminie również pomiędzy publikacjami.
Data aktualizacji i ostatniego sprawdzenia są widoczne na stronie.
Przed złożeniem oferty sprawdź zmiany i komunikaty zamawiającego.

Nowe dane publikuje lokalny agent. Repozytorium zawiera tylko stronę;
nie zawiera lokalnej bazy, skanów, konfiguracji firmy ani danych logowania.
